## Правила актуализации

Архитектура описывает текущий код, roadmap — порядок развития, ВКР — целевую модель. Контракты, настройки и результаты конкретного эпика хранятся рядом с его спецификацией. При расхождении с исходным исследовательским каталогом для текущей реализации используется спецификация рабочего эпика.

Новый эпик оформляется в `docs/epics/epic-N/`: `README.md` с границами и критериями, дополнительные документы только по необходимости. Общие сведения не копируются — используются ссылки. В отчётах различаются выполненные проверки, исторические результаты и оставшиеся задачи. Пути к конфигам и команды указываются относительно корня репозитория.

[README проекта](../README.md) содержит быстрый старт. Локальные исследовательские заметки и артефакты остаются в игнорируемых `research/` и `results/`.
